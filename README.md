## Déploiement Vercel
1. Créer un repository GitHub.
2. Ajouter tous les fichiers du dossier.
3. Dans Vercel, importer le repository.
4. Framework Preset : `Other`.
5. Build Command : laisser vide.
6. Output Directory : `.`.
7. Deploy.

Le site utilise des images externes Unsplash pour les photos de destination/hero. Pour une version production, remplacer ces URLs par les photos officielles de Samba Travel Agency.
